# Social Media Frontend – HTML, CSS, JavaScript & Bootstrap

A responsive social media web application built as part of my frontend development journey.  
This project focuses on consuming REST APIs, handling authentication, and building dynamic, interactive UI components using clean and modular JavaScript.

🔗 **Live Demo:**  
https://melodic-cajeta-b0aaf1.netlify.app/

---

## 🎯 Project Overview

This application simulates a modern social media platform where users can register, log in, create posts, upload images, browse profiles, and interact with posts through comments.  
The project integrates a real backend API to manage authentication, CRUD operations, and user data.

---

## 🔌 Backend API

This project uses a custom backend API that I developed separately to handle authentication, posts, comments, and image uploads.

🔗 **API Repository:**  
https://github.com/hajarhr55/social-media-api

---

## ✨ Features

- User registration and login  
- Token‑based authentication  
- Create posts with optional images  
- Edit and delete personal posts  
- View all posts with pagination  
- View single post details  
- Add comments to posts  
- User profile page  
- Responsive layout for all devices  
- Dynamic modals for creating/editing/deleting posts  
- Loading indicators during API calls  
- Toast notifications for feedback  
- Persistent login using Local Storage  
- Responsive navigation bar  
- Image upload support via API  
- Clean and modular JavaScript structure
